# Stage 06 — Лес, дом и обзор

Статус: **Реализован**
Зависит от: Stage 02 (2D-персонаж), Stage 01 (сцены и камера)
Отчёт: `docs/reports/2026-10-01-stage-06-forest-house-and-visibility-report.md`

## Goal

Игрок находится внутри дома посреди леса и **видит только то, что видит**:
внутри — комнату вокруг себя, снаружи — узкий сектор через окно. Всё
остальное — темнота.

## Business value

Это первый этап, на котором хоррор перестаёт быть описанием и становится
механикой. Видимость превращается в ограничение: чтобы понять, что снаружи,
надо подойти к окну, а не просто посмотреть. Одновременно появляется
пространство, в котором эту механику видно — до этого сцена была полом
с героем посередине.

## Scope

- Визуальное направление по референсам Scorched Sun и Darkwood
- Персонаж: покадровые спрайты строго сверху, покой и шаг
- Окружение: лес вокруг дома, дом в центре
- Дом: пол, стены, окна, встроенные в стены, обстановка
- Обзор: стены режут обзор, снаружи видно только через окно, угол
  считается из окна
- Атмосфера: темнота, туман, пост-обработка

## Out of scope

- Сеть и репликация обзора
- Враги и их восприятие
- Источник света как ресурс (фонарь, батарея) — это остаток Stage 04
- Взаимодействие с предметами (двери, рычаги)
- Восемь направлений персонажа
- Производительность: профилирование не выполнялось
- Второй этаж, подвал, несколько комнат

## Work

### Графика
- Процедурные спрайты: персонаж, пол, земля, стены, окно, деревья, кусты,
  туман, обстановка. Генераторы лежат в `.workbuddy-ai/tools/`
- Палитра снята со скриншотов референсов: холодная, обесцвеченная, тёмная
- Персонаж — покадрово (см. ADR 0009), один набор, четыре направления
  поворотом узла `Visual`

### Gameplay
- `Assets/Scripts/Gameplay/Perception/` — обзор как слой восприятия
- Чистая логика (`VisionCone`, `VisionFanBuilder`, `VisionPolygonBuilder`)
  отделена от MonoBehaviour и тестируется без сцены
- Источник обзора один — игрок (круг). Окна и двери источниками не являются:
  это проёмы в геометрии, обзор проходит через них сам

### Rendering
- Маска видимости в RenderTexture и слой темноты поверх кадра
- Рендер-пайплайн не меняется — см. ADR 0008

### Level
- Сцена `Game`: земля, лес из 64 деревьев, дом с четырьмя стенами,
  двумя окнами и дверным проёмом, обстановка

## Acceptance criteria

- [x] Персонаж — 2D-спрайт строго сверху: видны голова и плечи
- [x] При ходьбе появляются руки и ноги
- [x] Набор анимаций: покой и ходьба, оба зациклены
- [x] Лес вокруг дома, дом в центре
- [x] Пол, стены и окна в доме
- [x] Персонаж не видит за стенами
- [x] Снаружи видно только через окно — окно работает как обычный проём,
      без отдельной логики
- [x] Обзор обрезается препятствиями (стены и мебель)
- [x] Тёмное освещение и туман
- [x] EditMode-тесты на всю чистую логику обзора
- [x] PlayMode-тест: полигон обзора не выходит за стену

## Required tests

- **EditMode:** `VisionConeTests`, `VisionFanBuilderTests`,
  `VisionPolygonBuilderTests`, `PlayerFacingTests`, `PlayerAnimationTests`
- **PlayMode:** `VisibilityOcclusionTests`

## Risks

- **Читаемость против атмосферы.** Уже реализованный риск Stage 04.
  Митигация: скриншоты на каждом шаге, а не «на глаз в редакторе».
- **Рейкасты каждый кадр.** Не измерялось. При росте числа источников
  обзора стоимость вырастет линейно.
- **Референсы — две игры, обе не наши.** Взята атмосфера и палитра,
  но не композиция и не механики.
