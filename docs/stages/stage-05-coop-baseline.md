# Stage 04 — Coop Baseline

Статус: **Не начат**
Зависит от: Stage 02, ADR 0003 (сетевой стек)

## Goal

Два игрока в одной сессии видят друг друга, двигаются вместе, и свет каждого виден обоим.

## Business value

Это первая стадия, где **кооператив перестаёт быть лозунгом**. Всё, что делается после, опирается на эту: если сетевой seam неверен, все последующие фичи придётся переделывать. Отсюда и размер этапа — он маленький по объёму, но критический по значимости.

## Scope

- Выбор и установка сетевого пакета (по ADR 0003)
- Транспортный seam: `INetworkService` в `Core`, реализация в `Net/`
- Спавн игрока — только на authority
- Репликация позиции с интерполяцией
- Локальный и удалённый игрок — **один и тот же** `PlayerController`
- Join / leave
- Один общий класс для local и remote игрока
- Базовый UI: список подключённых игроков
- EditMode-тест на seam: `INetworkService` подменяется заглушкой, геймплей работает без сети
- PlayMode-тест: два инстанса в одной сцене

## Out of scope

- Ходьба/бег в сети сверх минимального
- Свет в сети (кроме базовой репликации состояния)
- Здоровье, урон, смерть
- Враги и их ИИ в сети
- Предметы, инвентарь, взаимодействие
- Слои Late join
- Dedicated server
- Античит, валидация клиента
- Реконнект

## Work

### ADR (до кода!)
- `docs/adr/0003-networking-stack.md` — выбор пакета, тикрейт, authority-модель
- Это **блокирующий** артефакт. Нет ADR — нет кода.

### Net
- `Assets/Scripts/Net/` — единственное место с сетевым кодом
- `NetworkService : INetworkService`
- Ни одного сетевого API вне `Net/`

### Core
- `INetworkService` — интерфейс: `IsAuthority`, `IsSpawned`, события спавна
- Геймплей общается только с интерфейсом

### Gameplay
- `PlayerController` не меняется архитектурно. Только источник ввода:
  local → `IInputReader`, remote → реплицированное состояние

### UI
- Список игроков. Презентация только.

## Acceptance criteria

- [ ] ADR 0003 написан и принят
- [ ] Сетевой пакет установлен, версия зафиксирована в `AGENTS.md`
- [ ] **Ноль сетевых API за пределами `Assets/Scripts/Net/`** — проверяется grep'ом
- [ ] **Ноль `if (isNetworked)` в геймплейном коде** — один seam в `Net/`
- [ ] Два игрока видят движение друг друга
- [ ] Удалённый игрок интерполируется, не дёргается
- [ ] Локальный и удалённый игроки — один класс
- [ ] Спавн происходит только на authority
- [ ] Join и leave работают без ошибок в консоли
- [ ] EditMode-тест: геймплей работает с заглушкой `INetworkService`, без сети
- [ ] Геймплейный код компилируется и работает **без** сетевого пакета (за счёт абстракции)

## Required tests

- **EditMode:** `NetworkSeamTests` — `INetworkService` заглушка, геймплей не падает
- **PlayMode:** два инстанса игрока, оба обновляются, join/leave без утечек
- **Grep-проверка:** ни одного сетевого API вне `Net/`, ни одного `isNetworked` в геймплее

## Risks

| Риск | Митигация |
|---|---|
| Неправильный выбор пакета | ADR до кода. Это главный риск stage |
| Сеть протекла в геймплей | Grep-проверка в acceptance criteria |
| Локальный и удалённый игрок разошлись в коде | Один класс — требование, не рекомендация |
| Тизк слишком частый для хоррора | Профилирование на 4 игроках, см. `performance-budget.md` |
| Сложность отладки сетевых багов | Сначала подтвердить seam тестом, потом добавлять репликацию |
