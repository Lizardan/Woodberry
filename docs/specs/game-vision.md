# Spec — Game Vision

Статус: Draft
Обновлено: 2026-09-30

## Что это

Woodberry — кооперативный хоррор с видом сверху. Камера и читаемость — в духе GTA 2: игрок всегда понимает, где он, куда смотрит и что находится вокруг, даже когда сцена почти чёрная. Атмосфера — тревожная, мрачная, построенная на том, чего игрок **не видит**, а не на том, что он видит.

## Ключевые решения

| Решение | Обоснование |
|---|---|
| Вид сверху, а не от первого/третьего лица | Кооператив требует читаемости позиций друг друга. Вид сверху даёт это бесплатно. |
| Тёмная сцена, ограниченная видимость | Источник напряжения — неизвестность, а не gore |
| Кооператив — архитектурное ограничение, не фича | Сеть влияет на каждый модуль. Проще строить с учётом этого с первого дня |
| Мультиплеер без «хост-特权» | Игроки равны, значит game state реплицируется всем, а не «владельцу» |

## Атмосфера — что именно пугает

1. **Ограниченная видимость.** Игрок видит конус света и то, что подсвечено. Всё остальное — тьма и силуэты.
2. **Звук важнее картинки.** Шаги, дыхание, скрипы — источник информации, которого у игрока нет визуально.
3. **Неизвестная карта.** Первый раз уровень пугает. Второй раз — уже нет. Значит, опасность должна быть в темноте и в неопределённости, а не в memorize-механике.
4. **Редкие, но громкие события.** Тишина важнее скримера. Не пиши «кричащий» дизайн.

## Чего в игре НЕТ (осознанно)

- Скримеров как основного инструмента
- Мгновенной смерти от неожиданности
- Скриптовых QTE
- Режима «один игрок проходит, остальные смотрят»

## Игровая петля (первая версия)

```
Осмотреться → Найти источник света / ресурс → Взаимодействовать → Рискнуть дальше →
Либо получить награду, либо спугнуть угрозу → Отступить, чтобы перегруппироваться
```

## Тон коммуникации

Интерфейс минимален. HUD не должен показывать всю информацию — часть хоррора в том, что игрок не знает. Но **информация о состоянии персонажа обязана быть читаемой** (здоровье, свет, ресурсы) — иначе кооператив ломается: игроки перестают понимать друг друга.
