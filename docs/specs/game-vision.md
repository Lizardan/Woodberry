# Spec — Game Vision

## Что это

Woodberry — кооперативный детективный хоррор с видом сверху. Камера и
читаемость — в духе GTA 2: игрок всегда понимает, где он, куда смотрит и что
находится вокруг, даже когда сцена почти чёрная. Атмосфера — тревожная,
мрачная, построенная на том, чего игрок **не видит**, а не на том, что он видит.

Полный замысел игры — `../gdd/00-vision.md`. Этот spec — обязывающие
ограничения для кода и арта, а не описание дизайна.

## Ключевые решения

| Решение | Обоснование |
|---|---|
| Вид сверху, а не от первого/третьего лица | Кооператив требует читаемости позиций друг друга. Вид сверху даёт это бесплатно. |
| Тёмная сцена, ограниченная видимость | Источник напряжения — неизвестность, а не gore |
| Кооператив — архитектурное ограничение, не фича | Сеть влияет на каждый модуль. Проще строить с учётом этого с первого дня |
| Мультиплеер без «хост-привилегий» | Игроки равны, значит game state реплицируется всем, а не «владельцу» |
| Угроза спрятана среди жителей | Главный конфликт — социальный и информационный, а не боевой |

## Атмосфера — что именно пугает

1. **Ограниченная видимость.** Игрок видит конус обзора и то, что в нём.
   Всё остальное — тьма. Технический контракт — `../adr/0008-visibility-and-darkness.md`.
2. **Звук важнее картинки.** Шаги, дыхание, скрипы — источник информации,
   которого у игрока нет визуально.
3. **Неизвестность, а не memorize-механика.** Деревня процедурна, но
   разгадываема: у неё есть одна логичная истина, а не набор случайностей.
4. **Редкие, но громкие события.** Тишина важнее скримера. Не пиши «кричащий» дизайн.

## Чего в игре НЕТ (осознанно)

- Скримеров как основного инструмента
- Мгновенной смерти от неожиданности
- Скриптовых QTE
- Режима «один игрок проходит, остальные смотрят»
- Экшен-боя как основного цикла вместо расследования
- Случайности ради случайности: деревня обязана быть логичной и разгадываемой

## Игровая петля

Две петли — внешняя (город) и внутренняя (деревня). Полное описание —
`../gdd/01-core-loop.md`.

### Внешняя — город (мета)

```
Город → гильдия: выбор заявки → подготовка → карета → миссия →
возврат в город → покупки и прокачка → ...
```

### Внутренняя — деревня (миссия)

```
Приезд → объявленный срок → расследование днём → ночь как угроза →
вычисление → приговор и казнь → исход (успех / провал)
```

## Тон коммуникации

Интерфейс минимален. HUD не должен показывать всю информацию — часть хоррора
в том, что игрок не знает. Но **информация о состоянии персонажа обязана быть
читаемой** (здоровье, рассудок, свет, ресурсы) — иначе кооператив ломается:
игроки перестают понимать друг друга.

Тон мира и атмосферы — `../gdd/06-world.md` и `../gdd/07-art-audio-ux.md`.
