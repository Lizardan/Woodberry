# Spec — Save System

Статус: Draft

## Что сохраняется

| Категория | Примеры | Реплицируется ли |
|---|---|---|
| Прогресс игрока | Позиция, инвентарь, здоровье, ресурсы | Нет — это локальное состояние каждого клиента |
| Мир | Открытые двери, подобранные предметы, потушенные огни | Да — общее для сессии |
| Настройки | Графика, звук, управление | Нет |
| Сессия | Активная сессия, кто подключён | Нет — живёт только в рантайме |

## Формат

- JSON для читаемости и diff'а при версионировании.
- Сериализация **вручную**, через DTO-классы. Не полагайся на `JsonUtility` для
  полиморфных или вложенных структур — он хрупок и не даёт версионирования.
- Один файл на слот. Имя: `save_slot_{n}.json`.
- Путь: `Application.persistentDataPath` (на всех платформах корректный). Не хардкодить.

## Версионирование

Обязательное поле `version` в корне файла.

Правило: **старый сейв должен открываться новым кодом** либо падать с понятным сообщением.
Молчаливое игнорирование неизвестных полей запрещено.

```
{
  "version": 1,
  "savedAtUtc": "2026-09-30T12:00:00Z",
  "sessionSeed": 12345,
  "world": { ... },
  "players": { ... }
}
```

## Ограничения

- Сохранение в сетевой сессии: запрещено. Сессия — рантайм-состояние, не сохраняемое.
- Частичное сохранение (записали, упали) должно быть безопасно: пишем во временный файл,
  потом атомарно переименовываем.
- Никаких секретов и персональных данных в сейве.
