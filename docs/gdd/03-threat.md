# GDD 03 — Угрозы деревни

Статус: Draft (каталог открыт для расширения)
Обновлено: 2026-10-05
Зависит от: `00-vision.md`, `01-core-loop.md`

## Зачем этот файл

Угроза — не только монстр. Игра должна пережить десятки сессий, значит нужен
**каталог проблем деревни**, которые генератор может смешивать. Ниже — стартовый
набор. Каталог пополняется, а не фиксируется.

## Свойства угрозы

Любая угроза описывается набором свойств; генератор комбинирует их.

| Свойство | Варианты |
|---|---|
| Природа | сверхъестественная / человеческая / средовая |
| Носитель | один житель / несколько / культ целиком / источник в месте |
| Маскировка | прячется в одном жителе / меняет облик / не имеет облика |
| Активность | только ночью / постоянно / по триггеру |
| Реакция на охоту | не знает / понимает и мешает / подставляет других |
| Чем вычисляется | показания / улики / святая атрибутика / алхимия / документы |
| Чем устраняется | казнь носителя / ритуал / уничтожение источника / изгнание |

| Угроза | Проявление | Как вычисляется | Как устраняется |
|---|---|---|---|
| Вампир | пьёт кровь, боится солнца и серебра | обескровленные тела, реакция на серебро | казнь, осиновый кол, солнце |
| Оборотень | зверские убийства по ночам | следы зверя, поведение днём, луна | казнь, серебро |
| Ведьма / колдун | порча, сглаз, ритуалы | странности, атрибуты, показания | казнь, очищение |
| Демон / одержимость | житель меняется, не помнит себя | святая вода, молитва, реакция | изгнание ритуалом |
| Упырь / нежить | поднимается после смерти | свежие могилы, слухи | освящение, огонь |
| Лесная тварь | нападения у леса | следы, раненые, слухи | охота, загон, капкан |

| Угроза | Проявление | Как вычисляется | Как устраняется |
|---|---|---|---|
| Культ | вербовка, тайные собрания | слухи, символы, пропажи | устранить главаря, разогнать |
| Секта / проповедник | раскол, добровольные жертвы | проповеди, показания | разоблачение, казнь |
| Отравитель | смерти без следов монстра | алхимия, доступ к еде и воде | казнь |
| Банда / вымогатели | страх, поборы | показания, запуганные жители | сила или хитрость |

### C. Средовая угроза

| Угроза | Проявление | Как вычисляется | Как устраняется |
|---|---|---|---|
| Чума | массовые смерти, паника | источник, крысы, вода | вычистить источник, карантин |
| Отравленный колодец | болезни от воды | алхимия, осмотр | найти виновного, очистить |

| Нашествие | твари из леса | наблюдение, слухи | загон, огонь, завал |

## «Не один»

Угроза может быть составной: монстр и пособники, культ и монстр, чума и
отравитель. Это повышает сложность и делает расследование нелинейным.
Генератор комбинирует свойства так, чтобы у деревни была **одна разгадываемая
истина**, а не набор случайных фактов.

## Правила генерации угрозы

- **Истина одна и логична.** Каждая улика либо ведёт к ней, либо отводит от
  ложного следа.
- **Ложные следы обязательны.** Без них детектив тривиален.
- **Угроза реагирует на расследование.** Чем ближе охотники, тем активнее она
  мешает.
- **Ночь — время активности.** Днём угроза маскируется.
