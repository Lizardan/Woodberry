# GDD 99 — Открытые вопросы и журнал решений

Статус: Living  
Обновлено: 2026-10-08

Живой документ. Здесь копятся нерешённые вопросы и фиксируются принятые  
решения. Правило: **принятое решение переезжает в профильный файл GDD, а здесь  
остаётся строка в журнале.**

## Открытые вопросы

### Мир и тон

- [x] Название мира и страны — не задаём: в тексте только «Инквизиция».
- [x] Религия: одна церковь, орден — её вооружённая рука → `06-world.md`.
- [x] Магии у охотника нет: атрибутика, алхимия и оккультика за рассудок →  
  `06-world.md`.
- [x] Природа сверхъестественного: не объясняем. Вместо объяснения — три  
  правила мира → `06-world.md`.
- [x] Приговор — **публичен**, деревня смотрит → `06-world.md`.
- [x] Ранги ордена — решено: **семь ступеней по огню** (фетиль, искра, свеча,  
  факел, костёр, пламя, солнце) → `02-player.md`.
- [x] Что даёт ранг — решено: **доступ, а не сила**. Открывает заявки, товары  
  торговца, занятия в городе, закрытые части монастыря, уважение, сюжетные  
  подарки → `02-player.md`.
- [x] Очки навыков — решено: даёт **опыт за разовые действия** (раскрытая улика,  
  найденный предмет, пойманный виновник, помощь в городе). Источники конечны и  
  одноразовы — фармить нечего → `02-player.md`.
- [ ] Враги ордена внутри церкви — **отложено**: не трогаем, пока не  
  понадобится.

### Игрок и инвентарь

- [x] Атрибуты (Сила / Ловкость / Вера / Разум) — **отложены** до боевой  
  системы. Сейчас только Жизни и Рассудок.
- [x] Уровни хранения — решено: сундук города **8×5** (расширяется), походный  
  сундук повозки **4×4**, **4 вещи** на себе, экипировка отдельно.
- [x] Слоты под зелья — решено: даёт **только пояс**, 1–4.
- [x] Выброшенный предмет — решено: **падает в мир**, можно подобрать.
- [x] Слоты экипировки — решено: **двенадцать** в четырёх группах (тело, руки,  
  вера, утилита) → `02-player.md`.
- [x] Сумка — это и есть панель особых предметов: **1 → 4 ячейки**, отдельного  
  списка нет. Сколько ячеек — столько предметов на миссию → `02-player.md`.
- [x] Руки — **динамические**: что взял, то и держишь. Предметы одноручные и  
  двуручные; арбалет занимает обе руки, значит без света → `02-player.md`.
- [x] Роли убранного плаща не нужны: скрытность и ночной обзор — не механики,  
  охотник не прячется, он власть → `02-player.md`.
- [x] Стопки — решено: **только у расходников** (зелья, травы, бинты, свечи,  
  шипы) по 5–10; снаряжение и реликвии поштучно → `02-player.md`.
- [x] Особые ёмкости — решено: **ровно три** — ключница (ключи), сумка (особые  
  предметы), пояс (зелья). Других нет → `02-player.md`.

### Повозка

- [x] Внешний вид — решено: **модули видно на повозке**.
- [x] Порядок работы — решено: сначала каталог модулей и улучшений, из него  
  выводим число уровней.
- [ ] **Каталог модулей и улучшений повозки** — что даёт, как меняет миссию.
- [x] Дорога — решено: **просто переход**, случайных событий в пути нет →  
  `04-levels.md`.

### Оккультика и рассудок

- [x] Ложная подсказка — решено: **никогда**. Ритуал сужает круг или указывает  
  направление, но не врёт.
- [ ] Полный каталог ритуалов, оккультных предметов и артефактов.
- [x] Шанс безумия — решено: **нет**, цена рассудка фиксированная.
- [ ] Стоимость каждого ритуала в рассудке — конкретные числа (контент).
- [ ] Восстановление: полный список расходников и сколько даёт отдых.

### Миссия

- [x] Структура дня — решено: **четыре фазы** (утро / день / вечер / ночь).
- [x] Срок — решено: **не фиксирован**, зависит от сложности заявки и условий  
  деревни.
- [x] Покинуть деревню до приговора — решено: **нельзя**. Начатое задание не  
  отменяется: выполнить, провалить или умереть.
- [x] Что теряет деревня за ночь — решено: **жителей**, число зависит от угрозы.
- [x] Чем измеряется фаза — решено: **таймером**.
- [x] Что если игроки разошлись по фазам — снято: фаза общая, идёт по таймеру.

### Игрок

- [x] Инвентарь — решено: четыре уровня хранения, см. «Игрок и инвентарь».
- [x] Смерть — решено: угроза, жители, дикие звери, среда, состояние, орден.  
  В коопе — «тяжело раненый» в повозке.
- [x] Навыки — решено: флаги, изучены **деревом из трёх веток** с нодами.
- [x] Собака-ищейка — решено: особый предмет на миссию, занимает слот.
- [x] Алхимия — решено: зелья варятся из трав, найденных в деревне и лесу.
- [ ] **Три ветки навыков и их содержимое** — форма есть, наполнения нет.
- [ ] Что именно открывает каждый навык: какие реплики, какие действия в мире.
- [ ] Список трав, рецептов и где они растут.

### Кооператив

- [x] Масштабирование ночи — решено: **не масштабируется** по числу игроков.
- [x] Выбывший игрок — решено: «тяжело раненый» в повозке, наблюдает до конца.
- [x] Прогресс гостя — решено: уезжает с ним, см.  
  `../adr/0011-character-and-world-saves.md`.
- [x] Late join — решено: **только в городе**.
- [x] Связь — решено: своих средств игра не даёт, расчёт на внешний голос.
- [ ] Проверить на практике, не стал ли кооп заметно легче соло, см. `05-coop.md`.

### Мета

- [x] Репутация — решено: **видимая шкала** с порогом казни.
- [x] Экономика — решено: **монеты с тесными ценами**, за миссию примерно на  
  одну-две вещи.
- [ ] Точные значения шкалы репутации и порог казни.
- [ ] Прайс-лист: сколько стоит снаряжение, расходники, модули повозки.
- [x] Сохранение при нескольких игроках — решено: переносится **персонаж**, мир  
  остаётся хозяину сессии, см. `../adr/0011-character-and-world-saves.md`.

### Техника (влияет на дизайн)

- [x] Степень процедурной генерации — решено: **модульная сборка** из готовых  
  кусков по правилам, не свободная геометрия.
- [x] Объём арта — решено: **пул портретов на роль + фон на локацию**, растим  
  постепенно (сначала странники и главы, потом остальные роли).
- [x] Набор эмоций — решено: **позже**, сейчас одна поза на персонажа.
- [x] `docs/stages/` разъехался: нумерация в заголовках не совпадала с именами  
  файлов, статусы устарели, `stage-06` был в папке, но не в списке.
