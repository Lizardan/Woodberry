## Product Overview

Пайплайн генерации арт-ассетов для игры Woodberry, расположенный в `F:\ai`. Генерирует поясные портреты NPC (для диалоговых сцен в стиле визуальных новелл) и фоны локаций. Результат композируется: персонаж накладывается на фон в диалоговой сцене. В самой игре — вид сверху, спрайты 128×128 (отдельный пайплайн, ADR 0009).

## Core Features

- Исправить рассинхрон размеров в `РЕЦЕПТ.md` (п.1: 512×768 → 480×720, 896×512 → 856×480)
- Синхронизировать `gen.GEN` с `scene.SUBJECT_SIZE`/`scene.BACKGROUND_SIZE`
- Актуализировать описание `cutout.py` в README (резервный метод, не основной)
- Инициализировать git-репозиторий с `.gitignore` для `F:\ai`
- Проверить и задокументировать лицензии моделей для коммерческого использования

## Tech Stack

- Python 3.12 + PyTorch 2.9.1 + ROCm 7.2.1 (окружение `comfyenv`)
- ComfyUI (движок генерации, API-формат графа)
- Модель: Z-Image (REDZ-v1.5-Q8_0.gguf), Qwen3-4B (энкодер), ae.safetensors (VAE)
- BiRefNet_lite (сегментация/вырезание фона)
- Git для версионирования скриптов

## Implementation Approach

Правки точечные, без изменения логики пайплайна. Каждая правка — исправление рассинхрона документации с кодом или добавление отсутствующей инфраструктуры (git, лицензии).

**Ключевые решения:**

1. `РЕЦЕПТ.md` п.1 строка 60: заменить `(512, 768)` → `(480, 720)` и `(896, 512)` → `(856, 480)`, чтобы совпадало с `scene.py:634-635` и с п.8 того же файла. Также обновить комментарий про `seed_base=880000` (в РЕЦЕПТе не указан, в scene.py есть).
2. `gen.py` строка 167: заменить `GEN = dict(width=512, height=768, steps=10, cfg=1.0)` на `GEN = dict(width=480, height=720, steps=10, cfg=1.0)`. Размер — дефолт для `build_workflow`, всегда переопределяется в `shoot.py`, но должен совпадать со стандартом, чтобы не вводить в заблуждение.
3. `README.md` строка 48: уточнить описание `cutout.py` — «библиотека расчёта альфы (резервный метод хромакея; основной — seg.py/BiRefNet; импортируется как fallback)».
4. Git: создать `.gitignore` (исключить `comfyenv/`, `ComfyUI/`, `models/`, `python312/`, `logs/`, `portraits/out/`, `portraits/raw/`, `portraits/_warm/`), `git init`, `git add` скриптов и документации, начальный коммит.
5. Лицензии: проверить HuggingFace-страницы каждой модели, записать в `F:\ai\LICENSES.md` название, источник, лицензию, статус коммерческого использования.

## Implementation Notes

- **Blast radius**: правки 1-3 — только документация и дефолт-константа, не влияют на рантайм (размер всегда передаётся явно через `shoot.py`).
- **Git**: `.gitignore` обязан исключать бинарники (`comfyenv/` 6 ГБ, `models/` 10 ГБ, `ComfyUI/` 60 МБ). В репозиторий попадают только `.py`, `.md`, `.yaml`.
- **Лицензии**: REDZ-v1.5 — квант Z-Image (проверить лицензию Z-Image на HuggingFace). Qwen3-4B — лицензия Apache 2.0 (ожидается, подтвердить). ae.safetensors — VAE от Flux (Apache 2.0, подтвердить). BiRefNet_lite — MIT/Apache (подтвердить).
