# Patterns — Whitelist

Разрешённые практики Woodberry. Всё, чего здесь нет — требует явного обоснования.

## Архитектура

| Разрешено | Почему |
|---|---|
| `Gameplay` → `Core` | Направление вниз |
| `UI` → `Gameplay` (через абстракции) | UI подписывается на геймплей |
| `AI` → `Gameplay` (через сенсорные абстракции) | Поведение потребляет правила |
| `Net` → `Core` | Реализует интерфейс |
| `Editor` → всё | Только в редакторе |
| Composition root в `Core`, собирающий зависимости вниз вверх | Единственное исключение из правила «вниз» |
| Один класс для local и remote игрока | Критично для кооператива |
| Чистая логика без `MonoBehaviour` | Тестируемость |
| SO как дизайн-данные | Дизайн-параметры |
| `OnValidate` для инвариантов SO | Ошибки в редакторе, не в игре |
| События из `Core` для рассылки состояния | Явные подписки |

## Код

| Разрешено | Почему |
|---|---|
| `[SerializeField] private` + property | Инспектор + контроль |
| `Try`-паттерн / `bool`-возврат | Возможна неудача — отражай в типе |
| `Awake` для кэширования, `Start` для логики | Порядок Unity |
| `OnEnable`/`OnDisable` парой | Нет утечек |
| Кэширование `GetComponent` в `Awake` | Производительность |
| Пул объектов | Частые спавны |
| Linq в редакторе/инициализации | Допустимо вне hot path |
| `foreach` по массиву | Быстро |
| `readonly` для неизменяемого | Явность |
| Модули в `Assets/Scripts/Net/` | Единственное место с сетью |
| `IInputReader` в `Core/` | Единственная точка ввода |
| Локальные логгеры | Диагностика |

## Тесты

| Разрешено | Почему |
|---|---|
| EditMode на чистой логике | Быстро, герметично |
| PlayMode на жизненном цикле | Нужна реальная среда |
| `WaitUntil` вместо `WaitForSeconds` | Не flaky |
| Создание объектов программно в тесте | Герметичность |
| `LogAssert.ignoreFailingMessages` для ожидаемых ошибок | Явно |
| Grep-проверки архитектурных границ | Автоматизация правил |

## Ассеты

| Разрешено | Почему |
|---|---|
| `Assets/Woodberry/<Category>/` | Ордер |
| `PascalCase` для имён | Согласованность |
| Префабы для повторяющихся объектов | Источник правды |
| Запечённый свет для статики | Производительность |
| `MaterialPropertyBlock` для вариаций | Не ломает батчинг |
| GPU instancing, static batching | Draw calls |
| Точечные `.meta` файлы | Стандарт Unity |

## Процесс

| Разрешено | Почему |
|---|---|
| Маленькие ревьюимые инкременты | Управляемость |
| Вертикальные срезы | Ранняя интеграция |
| Отдельный review-проход | Находит drift |
| Spec до кода при смене контракта | Нет кодирования неопределённости |
| Экран-скриншот для ручной проверки | Визуальное не проверить автоматически |
| `docs/reports/` после этапа | Видимый прогресс |
| ADR для долгоживущих решений | Не теряется rationale |
