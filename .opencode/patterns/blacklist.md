# Patterns — Blacklist

Запрещённые практики Woodberry. Каждая нарушает одну из границ или один из инвариантов
проекта. **Обнаружение — ошибка на review, а не стилистическое замечание.**

## Блокирующие (Critical)

| Паттерн | Почему блокирует | Раздел `AGENTS.md` |
|---|---|---|
| Сетевые API вне `Assets/Scripts/Net/` | Утечка транспорта в геймплей | Architecture rules |
| `if (isNetworked)` / `IsServer` в геймплее | Сеть протекает в правила | Multiplayer Do/Don't |
| Клиент как source of truth | Рассинхрон, читерство | Multiplayer Do/Don't |
| Ручной YAML-редакт `.unity` / `.prefab` | Тихая поломка ассетов | Unity-specific rules |
| Удаление `.meta` вручную | Битые ссылки у всей команды | Unity-specific rules |
| Runtime-код ссылается на `UnityEditor` | Editor-слой в player-сборке | Layer responsibilities |
| `Gameplay` → `UI` | Нарушение направления слоёв | Правило зависимостей |
| `Core` → `Gameplay` | Нарушение направления слоёв | Правило зависимостей |
| Заявление «готово» без запуска проверок | Ложная верификация | Verification commands |
| Подавление ошибок ради зелёного результата | Скрытые баги | Code quality rules |
| `git push` / `git reset --hard` / `rm -rf` | Риск потери работы | instructions/safety.md |

## Серьёзные (Important)

| Паттерн | Почему плохо | Где проверяется |
|---|---|---|
| `FindObjectOfType` в геймплее | Скрытая зависимость, нетестируемо | Grep |
| `Resources.Load` для геймплейных данных | Блокирует сборку, не масштабируется | Grep |
| Бизнес-логика в UI-контроллере | Нарушение слоёв | Review |
| SO как runtime-состояние | Баг: ассет общий для всех экземпляров | Review |
| Разные классы для local и remote игрока | Расхождение кода | Grep + review |
| `InputSystem` вне `Core` | Утечка устройства в геймплей | Grep |
| Строковые имена input-экшенов | Хрупко, ломается при переименовании | Grep |
| `public`-поля в рантайме | Нет контроля, не инспектор | Review |
| `GetComponent` в `Update` | Производительность | Grep + review |
| `new` / LINQ / строковая конкатенация в `Update` | Аллокации, GC | Review |
| `foreach` по `List<T>` с мутацией | `InvalidOperationException` | Review |
| Событие без парной отписки | Утечка, краш при domain reload | Review |
| `static event` без отписки | Утечка через domain reload | Grep |
| `Time.timeScale` в тестах без нужды | Ломает поведение | Review |
| `async void` вне coroutine-сценариев | Исключения теряются | Grep |
| Один класс решает две задачи (нужен «And» в имени) | Нарушение SRP | Review |

## Дисциплина процесса

| Паттерн | Почему плохо |
|---|---|
| Работать над несколькими stages сразу | Невозможно проверить, показать, откатить |
| Широкий рефакторинг без запроса | Непредсказуемый blast radius |
| Stage goal = «слой кода», а не возможность | Нельзя продемонстрировать |
| Пустой `Out of scope` | Неконтролируемый scope creep |
| Нет review-прохода | Drift не ловится |
| Нет stage report | Теряется контекст |
| Спека не обновлена при смене контракта | Contract drift |
| Spec для локального бага | Шум в документации |
| `TODO` без ссылки на issue/stage/ADR | Забывается |
| «Потом допишем тесты» | Тесты не появляются никогда |
| Верить памяти о Unity API | Устаревшие API = ошибки компиляции |

## Мёртвый код и мусор

| Паттерн | Почему плохо |
|---|---|
| Закомментированный код | Мусор, вводит в заблуждение |
| Неиспользуемые методы/поля/классы | Мёртвый вес |
| Необъяснённые хаки | Непонятно, почему так |
| Пустой `Update` | Unity вызывает каждый кадр впустую |
| `Debug.Log` в hot path | Стоимость и шум |
| Непонятный код без объяснения | Ломается при первом же изменении |

## Мусор в коммитах

| Паттерн | Почему плохо |
|---|---|
| `Library/`, `Temp/`, `Logs/`, `obj/` | `.gitignore` их исключает |
| `.csproj`, `.sln` | Генерируются |
| Секреты, API-ключи | Компрометация |
| Ассет без `.meta` | Битые ссылки |
| Всё подряд в одном коммите | Неревьюимо |

## Как проверить

Полный набор grep-проверок — в `unity-architecture-review` skill.
Быстрая версия — `unity-architecture-review` § «Проверки».

Правило: **каждый пункт blacklist, который можно проверить grep'ом, должен
проверяться grep'ом.** Договорённости без автоматизации через год перестают работать.
