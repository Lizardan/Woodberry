Прочитай `AGENTS.md` и `docs/stages/README.md` перед началом.

Задача: $ARGUMENTS

Дай структурированный план:

1. **Понимание задачи** — своими словами
2. **Scope** — что входит
3. **Out of scope** — что НЕ входит, явно и подробно
4. **Acceptance criteria** — только проверяемые утверждения
5. **Work по слоям** — Core / Gameplay / Net / UI / Art / Editor / Tests
6. **Риски и митигации**
7. **Допущения** — что предположил без уточнения
8. **Верификация** — конкретные команды + критерии успеха
9. **Blast radius** — small / medium / large

Ограничения:
- Предпочитай минимальный жизнеспособный инкремент
- Stage goal — **ВОЗМОЖНОСТЬ** (что игрок может сделать), а не слой кода
- Предпочитай вертикальные срезы, а не послойную разработку
- Не расширяй scope без явной необходимости
- Если задача меняет контракт — укажи, какой файл из `docs/specs/` нужно обновить
- Если решение архитектурное — укажи, нужен ли ADR
- Не начинай реализацию, пока plan не согласован
